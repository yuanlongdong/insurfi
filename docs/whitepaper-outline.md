# InsurFi 白皮书大纲

## 摘要 (Abstract)

- 问题：合约交易者面临无常亏损，传统保险无法覆盖链上交易场景
- 方案：InsurFi — BSC 链上首个面向合约交易者的交易亏损保险协议
- 核心创新：持仓即参保、链上亏损自动校验、BNB 即时赔付
- 愿景：成为 DeFi 领域的模块化保险基础设施

## 1. 引言 (Introduction)

### 1.1 背景
- DeFi 交易市场规模与交易者亏损现状
- 传统保险在加密领域的空白
- 链上保险的可行性与挑战

### 1.2 问题陈述
- 合约交易者无风险对冲工具
- 现有 DeFi 保险项目（Nexus Mutual、InsurAce）侧重智能合约风险，不覆盖交易亏损
- 中心化交易所保险产品透明度低、门槛高

### 1.3 解决方案概述
- InsurFi 协议定位与核心价值主张
- 与现有保险项目的差异化对比

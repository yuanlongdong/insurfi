# InsurFi

> BSC链上面向合约交易者的交易亏损保险 DeFi 协议

## 项目定位

InsurFi 不是保本盘，不是 meme 币，是**工具型保险协议**。用户持有 `INSUR` 代币即可自动激活保险保单，在指定 DEX/合约接口产生链上交易亏损后，经链上校验由保险池以 BNB 赔付到钱包。

## 三层架构

```
┌─────────────────────────────────────────┐
│              DApp 前端层                 │
│   保单看板 / 理赔申请 / 保险池 / 治理    │
├─────────────────────────────────────────┤
│              保险池层                    │
│   BNB资金池 / 亏损校验 / 保单管理 / 赔付  │
├─────────────────────────────────────────┤
│              代币层                      │
│   INSUR BEP20 / 持仓快照 / 权益激活      │
└─────────────────────────────────────────┘
```

## 核心机制

1. **持仓即参保**：持有一定数量 `INSUR` 代币，自动激活保险保单，无需额外付费
2. **链上亏损校验**：用户在指定 DEX/合约接口交易，亏损数据通过链上交易记录校验
3. **BNB 赔付**：校验通过后，保险池 BNB 直接赔付到用户钱包
4. **保单分级**：不同 INSUR 持仓量对应不同保障上限（迭代功能）

## 技术栈

- **链**：BNB Chain (BSC)
- **合约**：Solidity ^0.8.20 / Hardhat
- **前端**：Next.js + TypeScript + wagmi + viem
- **样式**：Tailwind CSS
- **RPC**：BSC Mainnet / Testnet
